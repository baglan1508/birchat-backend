## 2. Диалог с AI

Уже работает без изменений в приложении: `GET /ai/history` отдаёт **только сегодняшний** диалог (с полуночи по Алматы).

### Новые вопросы сверху

```http
GET /api/companies/{companyId}/ai/history?order=newest&limit=50
Authorization: Bearer {accessToken}
```

`messages` идут так: последний вопрос, ответ на него, предыдущий вопрос, ответ на него… То есть показывать список как есть, сверху вниз.

После нового вопроса (`POST /ai/ask`) вставлять пару «вопрос + ответ» **в начало** списка, а не в конец.

### Кнопка «Новый диалог»

```http
POST /api/companies/{companyId}/ai/history/clear
Authorization: Bearer {accessToken}
```

Ответ `204`. Удаляет вопросы и ответы пользователя в этой компании — после этого `history` пустой. Перед удалением стоит спросить подтверждение.

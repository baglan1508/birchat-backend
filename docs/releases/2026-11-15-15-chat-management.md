# Выпуск 15: удаление сообщения у всех, «кто прочитал», переименование группы, удаление компании

Ветка: `feature/chat-management` → `develop` (тест) → `main` (прод)
Запрос Flutter-разработчика. Старое приложение продолжает работать: добавлены только новые запросы.

## Что добавлено

| Запрос | Кто может | Что делает |
|---|---|---|
| `DELETE /chats/{chatId}/messages/{messageId}` | автор или директор | удаляет сообщение у всех |
| `GET /chats/{chatId}/messages/deleted?since=…` | участник чата | какие сообщения удалены после `since` — чтобы убрать их с экрана у остальных |
| `GET /chats/{chatId}/messages/{messageId}/readers` | участник чата | кто прочитал: `readCount` из `recipientsCount` и список |
| `PATCH /chats/{chatId}` `{name}` | директор | переименовать группу (общий чат — нельзя) |
| `DELETE /companies/{companyId}` | директор | удалить компанию |

### Как устроено

* **Удаление сообщения** — мягкое: сообщение остаётся в базе с пометкой (`deleted_at`, `deleted_by`, миграция `V21`), но пропадает из чата, поиска, сводок и контекста AI. Файл из удалённого сообщения пока остаётся в разделе «Файлы».
* **Кто прочитал** — отдельной таблицы нет: считается по существующим отметкам «прочитано до сообщения N» (`POST …/read`). Прочитал тот, чья отметка стоит на этом сообщении или позже. Автор и те, кто уже не в чате, не учитываются.
* **Удаление компании** — мягкое: компания получает статус `DELETED`, участия сотрудников — `COMPANY_DELETED`. Компания пропадает у всех из списка, любой запрос к ней — `403 NOT_A_MEMBER`, сводки по ней не считаются. Сообщения и файлы остаются — компанию можно восстановить вручную в базе.

Описание для приложения — `docs/flutter-next-build.md`, раздел 3.

## Проверка на тесте (staging), 15.11.2026

Деплой `588a8b9`, миграция V21. Через API: удаление автором — `204`, повторно — `204`, посторонним — `403`; сообщение пропало из списка; `messages/deleted` по `checkedAt` вернул удалённое, следующий запрос — пусто; переименование группы работает, общего чата — `400`; удаление компании — `204`, компания пропала из списка, запросы к ней — `403 NOT_A_MEMBER`.

Найдено: если подставить в `since` время телефона, удаление может потеряться (часы браузера спешили на 2 секунды). Исправлено: запрос без `since` отдаёт серверное время, документация обновлена.

# Выпуск 16: push-уведомления (APNs)

Ветка: `feature/push-notifications` → `develop` (тест) → `main` (прод)
По ТЗ Flutter-разработчика. Старое приложение не затронуто.

## Что добавлено

* `POST /api/devices` — регистрация устройства (токен APNs, `production`/`sandbox`, язык `ru`/`kk`); `DELETE /api/devices/{token}` — при выходе. Таблица `device_tokens` (миграция `V22`).
* При новом сообщении в любом чате — пуш всем участникам, кроме автора и тех, у кого чат открыт (опрашивали сообщения этого чата меньше 15 секунд назад).
* Уведомление: компания в заголовке, группа в подзаголовке, «Имя: текст» (до 100 символов, без строки ответа/пересылки), подписи вложений на языке устройства, бейдж — все непрочитанные получателя, `thread-id` — чат, `companyId`/`chatId`/`messageId` — для открытия чата по нажатию.
* Токены, которые Apple отклонил (`410 Unregistered`, `400 BadDeviceToken`), удаляются.
* При удалении аккаунта устройства пользователя удаляются.

### Как устроено

* Отправка — в фоне после сохранения сообщения (2 потока, очередь на 500): отправитель не ждёт Apple, сбой пушей не мешает сообщениям.
* APNs: HTTP/2, авторизация ключом `.p8` (JWT ES256, обновляется раз в 40 минут). Сервер Apple выбирается по `environment` устройства.
* «Чат открыт» хранится в памяти сервера: сразу после перезапуска человек с открытым чатом может получить лишний пуш.

### Что нужно для включения

Переменные на Render (тест и прод): `APNS_KEY_ID` и `APNS_PRIVATE_KEY` (содержимое файла `.p8`). Пока их нет, устройства регистрируются, но пуши не уходят. Team ID и Bundle ID заданы по умолчанию из ТЗ.

### Отличия от ТЗ

* `POST /api/auth/logout` не удаляет устройства (сервер не знает, с какого устройства выход; иначе пропали бы пуши на втором телефоне) — приложение вызывает `DELETE /api/devices/{token}`.
* Тихий пуш с новым бейджем после прочтения — не сделан («не срочно»).

## Тесты

`PushTextBuilderTest` (текст, обрезка, ответ, пересылка, подписи ru/kk), `ApnsClientTest` (JWT ES256 проверяется открытым ключом, чтение `.p8`, разбор ответов Apple, выбор сервера), `ChatPresenceTrackerTest`, `DeviceServiceTest` (перепривязка токена, чужой токен), `PushNotificationServiceTest` (получатели, полный JSON уведомления, удалённое сообщение, без ключа ничего не шлётся). Миграции V1–V22 в CI на PostgreSQL 18.

**Не проверено:** настоящая отправка в Apple — для неё нужен ключ `.p8` и устройство с приложением.

## Откат

Rollback деплоя на Render. Таблица `device_tokens` останется, старый код её не использует. Выключить пуши без отката — убрать `APNS_KEY_ID`.

# Выпуск 11: AI читает фото и PDF полностью

Ветка: `feature/ai-full-document-text` → `develop` (тест) → `main` (прод)
Только backend: приложению ничего менять не нужно.

## Что увидели

После выпуска 10 AI отвечал про фото, но по чеку знал только «это чек» и итоговую сумму — про позиции, магазин, способ оплаты ответить не мог. PDF-документы AI не читал вовсе: видел только метку `[документ]`.

## Причина

* Модель просили описать фото «в 1–3 предложениях» и переписать «главное» — она так и делала. Этого хватает для сводки, но не для вопросов по документу.
* PDF не обрабатывались.

## Что изменилось

### Фото — весь текст

Модель отвечает в виде:

```text
Что на фото: Кассовый чек магазина Magnum
Текст на фото:
ТОО «Magnum Cash&Carry», БИН 123456789012
Молоко 2,5% — 2 — 450 — 900
Хлеб — 1 — 250 — 250
ИТОГО: 1 150 ₸, оплата картой, 12.11.2026 21:40
```

Все позиции, количества, цены, БИН/ИИН, даты, способ оплаты; неразборчивое помечается `[неразборчиво]`. Лимит ответа модели 2500 токенов (хватает на чек в несколько десятков позиций), хранится до 8000 символов.

### PDF

* **PDF с текстом** (электронные чеки, счета, договоры, выписки) — текст читается на сервере библиотекой Apache PDFBox, без модели и без затрат: первые 20 страниц, до 8000 символов.
* **Скан в PDF** (картинки без текста) — первые 2 страницы превращаются в картинки, на время кладутся в хранилище рядом с файлом, их читает та же модель с «зрением», затем картинки удаляются.
* PDF с паролем пропускается (`SKIPPED`).
* PDF читается с диска, а не из памяти — сервер работает в 512 МБ.

### Что получает AI

* **В вопросах к AI** вложение передаётся целиком (до 6000 символов) — можно спрашивать «что купили по последнему чеку», «какой БИН у поставщика».
* **В сводке** — короче (до 1000 символов на вложение), чтобы сводка оставалась сводкой.
* **Документы — с именем файла**: `[документ: «Договор аренды.docx»]`, `[документ: «Чек Kaspi.pdf» — PDF, 1 стр.: …]`. Word и Excel пока не читаются, но AI знает, как они называются.

### Повторная обработка

Миграция `V18`: фото за последние 3 дня обрабатываются заново (с полным текстом), PDF за 3 дня — впервые. Сводки пересчитаются сами, когда появятся новые описания.

Миграция `V19`: эта обработка начинается через 3 минуты после миграции. При деплое Render около минуты держит старую версию приложения, и её фоновая обработка успевала забрать фото из очереди и снова сделать короткое описание (на тесте так и случилось). Файлы с отложенной попыткой старая версия не берёт.

## Проверка на тесте (staging), 13.11.2026

Деплой `5928b26`, миграция V18. В общий чат отправлены два PDF:

* «Чек Kaspi.pdf» (с текстом) → AI получил `[документ: «Чек Kaspi.pdf» — PDF, 1 стр.: Kaspi receipt, BIN 123456789012 / Milk 2 x 450 = 900 / Bread 1 x 250 = 250 / TOTAL 1150 KZT, card] Чек за продукты` — все строки;
* «Скан накладной.pdf» (страница без текста) → отрендерена на сервере Render, прочитана моделью (на тесте — заглушка), временная картинка удалена: `[документ: «Скан накладной.pdf» — PDF-скан, 1 стр.: …]`.

Обработка — в течение ~10 секунд после отправки. В логах: PDFBox один раз построил кэш шрифтов (`found 8 fonts`), ошибок нет.

Найдено: 4 файла из очереди V18 забрала старая версия приложения, ещё работавшая во время деплоя (`files=4` через 3 секунды после старта новой) — для этого добавлена V19.

## Стоимость

Для фото ответ модели длиннее — по-прежнему доли цента за фото. PDF с текстом — бесплатно (читает сервер).

## Тесты

* `PdfReaderTest`: весь текст чека из PDF; страница без текста — скан, рендерится в JPEG; длинный текст обрезается; пробелы и пустые строки схлопываются.
* `FileAnalysisServiceTest`: PDF с текстом читается без модели; скан — страница уходит модели, временная картинка удаляется; в очередь ставятся фото и PDF, но не Word.
* `AiServiceTest`: имя и текст документа доходят до AI; непрочитанный документ — по имени.
* `GlmAiProviderTest`: в запросе к модели — инструкция переписать весь текст, лимит 2500 токенов.
* CI: миграции V1–V18 на PostgreSQL 18.

## Откат

Rollback деплоя на Render. Миграция V18 только меняет статусы обработки — старый код их не использует. Остановить обработку — `AI_MEDIA_ENABLED=false`.

# Выпуск 21: push на Android (FCM)

Ветка: `feature/v16-fcm` (поверх выпусков 18–20) → `develop` (тест) → `main` (прод)
Пункт 1 из `BACKEND_TASKS_v1.6.md`.

## Что изменилось

* `POST /api/devices` принимает `"platform": "ANDROID"` с токеном FCM. Токен FCM чувствителен к регистру и хранится как есть (токен APNs, как раньше, — hex в нижнем регистре). `environment` для Android не нужен — сервер пишет `production`. Для iOS `environment` по-прежнему обязателен.
* Отправка — FCM HTTP v1 (`projects/{id}/messages:send`). Авторизация — сервисный аккаунт Firebase из переменной `FCM_SERVICE_ACCOUNT_JSON`: JWT (RS256) меняется на access token Google, токен держим 50 минут.
* Правила те же, что у APNs: всем участникам чата, кроме автора и тех, у кого чат открыт; упомянутым — всегда; тот же текст и язык.
* Сообщение по ТЗ: `notification` (`title`, `body`), `data` (строки: `companyId`, `chatId`, `messageId`, `title`, `body`), `android.priority = HIGH`, `android.notification.channel_id = messages`, `tag = chatId`. Название группы — в `title` через « · »; личный чат — имя автора.
* `UNREGISTERED` (404) и `INVALID_ARGUMENT` про токен — устройство удаляется (как `410` от APNs).
* Тихий пуш с бейджем — только iPhone (бейдж на Android рисует лаунчер).
* Пока `FCM_SERVICE_ACCOUNT_JSON` не задан, Android-устройства регистрируются, но пуши им не уходят; iOS работает как раньше.

## Настройка

`FCM_SERVICE_ACCOUNT_JSON` на обоих сервисах Render — см. `docs/environments.md`. Разработчику — `google-services.json` того же проекта Firebase.

## Тесты

* `FcmClientTest`: разбор сервисного аккаунта, подпись JWT проверяется открытым ключом; распознавание мёртвых токенов.
* `PushNotificationServiceTest`: Android получает сообщение FCM с группой в заголовке, `data` и `tag`; без ключа Firebase Android пропускается.
* `DeviceServiceTest`: токен Android сохраняется как есть, окружение `production`; iOS без окружения или с не-hex токеном — `400`.

## Откат

Rollback деплоя на Render. Android-устройства, зарегистрированные новой версией, старая будет пытаться отправить через APNs — Apple отклонит токен, и сервер удалит такие устройства; после повторного наката приложение зарегистрирует их снова при запуске.
